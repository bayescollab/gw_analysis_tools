Frequency-domain waveform for the EFPE eccentric-precessing model.

Evaluates the plus and cross polarizations of an eccentric, precessing binary inspiral at the requested frequencies using the pyEFPE SUA. Sets tolerances with pyefpe::ParameterPreset::Production.

Parameters
frequenciesArray of gravitational-wave frequencies in Hz
lengthNumber of elements in frequencies
wpOutput polarizations; hplus and hcross must be pre-allocated to length
paramsSource parameters — masses in solar masses, spins dimensionless, distance in Mpc, e_start and mean_anomaly_start for eccentricity
Returns
1 on success
Note
Only double precision is supported. Instantiation with ADOL-C adouble throws std::runtime_error at runtime.

Uniform-grid frequency-domain waveform for the EFPE eccentric-precessing model.

Identical to efpe_fourier_waveform() but uses the pyEFPE uniform-grid generator, which avoids per-frequency allocation and is the preferred path for where the analysis band is a fixed, evenly-spaced grid. The caller is responsible for ensuring that frequencies is uniform; no check is performed.

Parameters
frequenciesUniform array of gravitational-wave frequencies in Hz; f_min = frequencies[0], delta_f = frequencies[1] - frequencies[0]
lengthNumber of elements in frequencies
wpOutput polarizations; hplus and hcross must be pre-allocated to length
paramsSource parameters — same convention as efpe_fourier_waveform()
Returns
1 on success
Note
Only double precision is supported. Instantiation with ADOL-C adouble throws std::runtime_error at runtime.
