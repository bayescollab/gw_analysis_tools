Runs a Metropolis-Hastings chain from initial_params to locate good fiducial and test waveforms relative binning initialization.

Outputs detector responses: fiducial_out — response at the maximum-likelihood point found test_out — response at the last accepted point in the chain Caller must pre-allocate both output arrays as [num_detectors][data_length[i]]. If waveform generation fails for fiducial_out, it is set to the initial parameter point. If it fails for test_out, it is set to the max-likelihood point.

Parameters
dimensionSize of parameter space.
initial_paramsArray of parameters to begin exploration.
log_priorLog-prior probability function for the model.
param_scalesTypical scale for each parameter (e.g. prior width); used to size finite-difference steps for the Fisher diagonal.
num_mh_stepsNumber of M-H steps to be taken.
num_detectorsNumber of detectors.
dataThe signal at each detector whose fiducial waveform will be found for.
noise_psdThe PSD for each detector.
frequenciesFrequency arrays for each detector.
data_lengthLength of the signal for each detector.
gps_timeGPS time of the signal.
detectorsNames of the detectors.
generation_methodModel name for the output waveforms.
mod_structMCMC_modification_struct
fiducial_out[out] The fiducial signal.
test_out[out] The signal at the final M-H step.
test_gp_out[out] The parameters at the final M-H step.

Maximized match over coalescence variables - returns log likelihood NOT NORMALIZED for aligned spins.

Note: this function is not properly normalized for an absolute comparison. This is made for MCMC sampling, so to minimize time, constant terms like (Data|Data), which would cancel in the Metropolis-Hasting ratio, are left out for efficiency
